AETHERIA — a travel poster for a place that isn't there: floating isles above a sea of clouds, a waterfall pouring off the edge of the world, a lighthouse and a drifting balloon under a dusk sun. The image is drawn fresh in Python (`draw-poster.py`) and shipped as a single PNG by a tiny Node program (`main.ts`).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
